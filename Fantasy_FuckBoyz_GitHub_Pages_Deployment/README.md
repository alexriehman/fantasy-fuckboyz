# Fantasy FuckBoyz — GitHub Pages edition

Apple-style public fantasy dashboard built from the confirmed Week 7 2026 snapshot and 2021–2026 historical audit. Original dashboard layout and client-side season filters retained; postseason records preserve championship-winners-bracket-only treatment. 2021 team names are labeled assumptions, not independently ESPN verified.

## Publish for the league

1. Create a **public** GitHub repository named `fantasy-fuckboyz` (or another name) under your account.
2. Upload the **contents** of this package to the repository root, including `.github/workflows`, `data`, `scripts`, and `index.html`. The default branch in these workflow files is `main`.
3. In GitHub **Settings → Pages**, choose **GitHub Actions** as Build and deployment source.
4. In the Actions tab, run **Deploy GitHub Pages** if it has not run automatically. Once published, GitHub shows the verified Pages URL in **Settings → Pages**. Share that URL in your league chat.
5. The site has no login or secret in its public content. All published team statistics are publicly accessible.

## Weekly automation: what's ready and what's not

- `.github/workflows/weekly-update.yml` runs Tuesday around 9am **CST** (10am **CDT**) and can be run manually. GitHub Actions cron uses UTC; use an external DST-aware scheduler if you require exactly 9am year-round. GitHub's scheduled workflows may be delayed.
- `scripts/fetch_weekly.py` accepts `FFB_DATA_ENDPOINT` (GitHub **Actions repository secret**) and optional `FFB_DATA_TOKEN` (also a secret). It expects a full JSON snapshot matching `data/dashboard.json`.
- **No direct Flaim API access is provided by the ChatGPT Flaim connector.** The endpoint must be separately built and authorized using an official supported Flaim service/API or another explicitly authorized ESPN data source. Do **not** paste ESPN session cookies, account tokens, or Flaim credentials into the repository.
- Without an endpoint configured, scheduled actions **validate existing data only**; the website does **not** automatically refresh from ESPN. This is intentional to avoid pretending to have access or publishing fabricated results.
- The endpoint must return only finalized ESPN weeks, maintain the historical manager crosswalk, and preserve winners-bracket-only championship statistics. Validation aborts updates on missing or inconsistent weekly data. The source JSON may contain historical tables; do not overwrite historical records unless verified.
- Your preexisting ChatGPT Tuesday Flaim summary is separate and does not send its output to GitHub.

## Local testing

Run `python scripts/validate_and_publish.py` from the repository root. Open `index.html` locally or run `python -m http.server 8000` and visit http://localhost:8000.

## File structure

- `index.html` — design and interactions (Apple-inspired interface)
- `data/dashboard.json` — canonical snapshot (source of truth for publisher)
- `data/dashboard.js` — browser-loadable representation generated by validation script
- `scripts/validate_and_publish.py` — strict weekly integrity check
- `scripts/fetch_weekly.py` — plug-in point for an authorized external data endpoint
- `.github/workflows/weekly-update.yml` — scheduled data check and commit
- `.github/workflows/pages.yml` — automatic Pages deployment

### Historical caveat

This package preserves previously reviewed historical data and verification flags; the 2021 owner/team names were mapped by league-member assumption, not independently confirmed by Flaim. Do not publicize unreconciled historical aggregates as fully certified.
